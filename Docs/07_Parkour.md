# Parkour System

## Vision

Movement should feel fast, fluid, and satisfying.

Players should be encouraged to explore the world using parkour instead of simply walking.

---

# Core Movement

- Sprint
- Jump
- Double Jump (Late Game)
- Slide
- Crouch
- Dodge
- Roll
- Climb
- Vault
- Wall Run
- Ledge Grab
- Rope Swing
- Zipline
- Swim
- Dive

---

# Advanced Movement

Players can unlock:

- Dash
- Air Dash
- Grappling Hook
- Wing Suit
- Glider

---

# Parkour Challenges

Hidden throughout the world.

Rewards:

- XP
- Ancient Relics
- Cosmetic Items
- Skill Points

---

# Exploration

Players can reach:

- Mountain Peaks
- Ancient Towers
- Underground Ruins
- Floating Fragments
- Secret Caves

---

# Stamina

Actions consume stamina.

Higher levels increase:

- Sprint Distance
- Climbing Speed
- Wall Running Time

---

# Skill Tree

Movement Skills

↓

Advanced Movement

↓

Master Explorer

---

# Gameplay Goals

- Reward exploration
- Encourage creative movement
- Make traversal fun
- Reduce repetitive walking

---

# Inspiration

Movement should feel smooth and responsive like the best modern action-adventure games, while remaining unique to Project Unknown.
