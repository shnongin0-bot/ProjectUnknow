# Vision

Project Unknown is a mysterious open-world action-adventure where players explore a fractured world, uncover the secrets of an ancient civilization, master fluid movement, battle powerful enemies, build safe havens, and ultimately decide the fate of reality itself.

---

# Core Gameplay Pillars

## 1. Exploration

Every location should reward curiosity.

Players discover:

- Ancient Ruins
- Hidden Machines
- Secret Dungeons
- Lost Technology
- Hidden Bosses

---

## 2. Movement

Movement should always feel enjoyable.

Features:

- Sprint
- Climb
- Wall Run
- Slide
- Grapple
- Jump

---

## 3. Combat

Combat rewards skill rather than button mashing.

Features:

- Melee
- Ranged Weapons
- Parkour Combat
- Gadgets
- Boss Battles

---

## 4. Building

Players build:

- Bases
- Workshops
- Storage
- Defenses
- Crafting Stations

---

## 5. Vehicles

Vehicles help explore dangerous regions.

Examples:

- Motorcycle
- Hover Bike
- Truck
- Flying Vehicle (Late Game)
