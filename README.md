# Project Unknown

An original open-world third-person action-adventure game built with Unreal Engine 5.

## Vision
Project Unknown is a mysterious fractured world where players explore ancient ruins, uncover forgotten civilizations, fight powerful enemies, build bases, drive vehicles, and master parkour while discovering the truth behind **The Collapse**.

## Planned Features
- 🌍 Open World
- 🏃 Parkour
- ⚔️ Combat
- 🚗 Vehicles
- 🏗️ Building
- 📖 Story
- 🤖 Ancient Machines
- 🔍 Exploration

## Engine
- Unreal Engine 5
